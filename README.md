# Job Applecation readme.file 

A sleek, responsive job management interface designed for tracking applications. Built with **Tailwind CSS**, **DaisyUI**, and **Vanilla JavaScript**, this project focuses on a clean user experience for job seekers to manage their "Available," "Interview," and "Rejected" statuses.

 Features

  Dynamic Dashboard:** At-a-glance stats for available, interview-ready, and rejected applications.
* **Filter System:** Toggle between job categories using an interactive navigation menu.
* **Responsive Cards:** Detailed job listings including salary ranges, location, and job types that adapt to mobile and desktop views.
* **Status Management:** Individual buttons to move jobs through different stages of the recruitment pipeline.
* **Modern Typography:** Integrated with the **Geist** font family for a premium, tech-forward look.

 Tech Stack

| Technology Usage 
| **HTML5 Semantic structure of the portal 
| **Tailwind CSS v4 Modern utility-first styling 
| **DaisyUI Component library for buttons and cards 
| **JavaScript DOM manipulation and status toggling 
| **Google Fonts Geist typeface for modern UI .
